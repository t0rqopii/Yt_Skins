# Changelog

All notable changes to YouTube Theme Studio. Versions follow [semantic versioning](https://semver.org).

## [Unreleased]

## [5.0.0] - 2026-11-28

### Added
- **Shader lab**: animated WebGL backgrounds (plane, wave, sphere) with colors, speed, zoom, tilt, quality presets and pointer interaction.
- **Frames**: borders and glows around thumbnails, avatars or the whole site, optionally animated.
- **Custom cursor**: ring style or your own image.
- **Background finishing**: tint, vignette, brightness, saturation, contrast, position, zoom, flip, patterns (dots, grid, diagonal) and video speed.
- **Typography**: line height, word spacing, stretch, italic, underline and text case for each area, plus 4 bundled fonts (Manrope, Source Sans 3, Source Serif 4, Space Grotesk).
- **Player**: blend into the theme and adjustable corner radius.
- **Titles**: gradient angle, animated gradient and text shadow.
- Hide the page and sidebar scrollbars.

### Changed
- Redesigned studio interface.
- Themes and backups from 4.x import without changes.

## [4.2.0] - 2026-11-27

### Added
- Theme gallery in `themes/` with four starter themes: Midnight Tide, Sakura Dusk, Neon Arcade and Paper.
- Automated GitHub Releases: pushing a `v*` tag builds the extension zip.

### Changed
- Repository reorganised: extension source now lives in `extension/`.
